# Collections & History

Organization is critical when building complex network architectures. API360 utilizes a dual-system to ensure you never lose your work.

## History Tape

Every time you hit the **Send** button, API360 transparently serializes a snapshot of your entire request state (URL, Body, Headers) into browser LocalStorage.

The History tab on the bottom-left sidebar paints a chronological ledger of these snapshots.
* Click any historic row to instantly rehydrate the main workspace with the exact layout and payload from that moment in time.

## Collections

While History is automatic, Collections are intentional. 
Collections act as persistent folders where you can curate specific groups of endpoints (e.g., "Authentication API", "Payment Webhooks", "GitHub GraphQL").

1. **Creating Collections**: Click the `+` icon in the right side of the Collections sidebar header.
2. **Saving Requests**: In the top URL bar, click the `Save` disk icon. A modal will prompt you to name the request and select which Collection folder it belongs to.

*Saved requests persist securely in your local environment without needing a cloud account.*
